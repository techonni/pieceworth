# Pieceworth website UI kit
Click-through recreation of pieceworth.com built from `src/layouts/Base.astro` and `src/pages/**`.
Screens: Home, Guides index, Guide, Picks, Stores index, Store, About. Nav and list rows are clickable.
Guide step bodies, verdicts, pitfalls and store facts are bracketed placeholders — the real copy lives in `src/lib/content.ts`. Pick products are sample rows with striped image placeholders (real site hotlinks Impact catalog images).
